git commit
Creates a new commit from the changes that have been staged.

git commit -m 'message'
Creates a commit and uses the text in quotes as the commit message.
The -m argument means "message".

git branch
Shows the branches in the repository. The * shows which branch you are currently on.

git branch <branch-name>
Creates a new branch with the given name.

git checkout <branch-name>
Switches to the specified branch.

git checkout -b <branch-name>
Creates a new branch and switches to it.

git pull
Gets changes from a remote repository and merges them into the current branch.

git pull <remote> <branch>
Gets changes from the specified remote and branch, then merges them into the current branch.
Example: git pull upstream main

git push
Sends your local commits to the remote repository.

git push <remote> <branch>
Pushes the specified branch to the specified remote.
Example: git push origin main

git push -u <remote> <branch>
Pushes a new branch to the remote and sets it as the upstream branch.
Example: git push -u origin lesson2

git merge <branch-name>
Merges the specified branch into the branch you are currently on.

git rebase <branch-name>
Moves/reapplies your current branch's commits on top of the specified branch.

git fetch
Downloads information about changes from a remote repository without merging those changes into your current branch.

git fetch <remote> <branch>
Fetches information from the specified remote and branch.
Example: git fetch upstream main
